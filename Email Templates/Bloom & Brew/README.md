# Bloom & Brew — Promotional Email

## Project Overview

Bloom & Brew is a fictional coffee shop promotional campaign created as a portfolio project.

The project began as a visual email mockup designed in Canva and was then recreated from scratch using HTML and CSS.

## Features

- Responsive layout
- Promotional CTA button
- Hover interaction
- Responsive coffee imagery
- Custom typography and color styling
- Mobile-friendly layout

## Technologies

- HTML5
- CSS3
- Canva
- GitHub
- GitHub Pages

## Design Process

1. Created the original promotional design in Canva.
2. Built the HTML structure in Visual Studio Code.
3. Added custom CSS styling.
4. Added responsive sizing for smaller screens.
5. Added a hover interaction to the CTA button.
6. Tested the layout at multiple mobile widths.
7. Deployed the project using GitHub Pages.
